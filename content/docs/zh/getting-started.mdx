# 快速开始

Previously 跑在你自己的机器上：一个 npm 包就是整个产品。你只需要记住一条命令。

**要求**：Node.js ≥ 20。不需要 Docker，不需要装 git。

## 安装

```bash
npm i -g previously-client
previously
```

## 第一次运行：一个向导

裸 `previously` 是前门。第一次运行时，它会在终端里带你走一遍初始化向导，把一切都安顿好：

1. **安顿运行区** —— 创建 `~/.previously`，放内核版本、日志和进程状态。
2. **安顿记忆** —— 在 `~/Documents/Previously` 创建你的记忆仓库；如果那里已经有一个 Previously 仓库（比如从备份克隆回来的），它会直接领养，历史原样保留。
3. **选一个引擎** —— 向导会探测你 PATH 上已有的 agent CLI（Claude Code、Codex、Kimi Code），并建议把探测到的订阅配置为 bridge 引擎：零 API key、零额外费用。没探测到，或者你更想自己带 key，它会问你要一个 API key（BYOK）。两条路的取舍见[双引擎](/docs/two-engines)。
4. **转录已有历史** —— 把你本机其他 agent 的既有对话记录转录成时间线上的切片。这一步不消耗任何 token——转录是确定性的解析，不是模型调用。

任何会消耗 token 的步骤，向导都会先给你估账，并默认不执行。没有任何一步是悄悄花你钱的。

## 启动，打开，开始聊

```bash
previously start   # 后台启动内核
previously open    # 在浏览器里打开 Web UI
```

Web UI 在 `127.0.0.1:3210`——只有你自己的机器能访问。打开它，输入你的第一条消息。这条消息会打开你时间线上的**第一个切片**：从这一刻起，记忆开始累积。

没有账号注册，没有数据库配置，没有种子数据。

## 仪表盘：`previously status`

跑起来之后，裸 `previously`（或 `previously status`）就是你的仪表盘：内核是否在运行、Web UI 地址、记忆仓库状态、引擎探测结果、转录进度。日常的开、关、看日志都在[日常](/docs/everyday)里。

## 先在浏览器里试试

想在安装之前感受一下产品？[回忆](/docs/recall)这篇文档里有几个可以直接点的问题——Previously 就着一段真实记忆当场作答，带原文引用，无需任何安装。
