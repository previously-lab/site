# 快速开始

<Callout variant="info">
没有对话列表，没有线程管理，没有"新建聊天"按钮。时间线就是对话列表——一条从你最早记忆到 NOW 的水平点线。你出现、交谈，记忆自动形成。
</Callout>

Previously 用一条水平时间线上组织的单一、持续的关系取代了聊天线程。agent 形成对你的持久化理解。它实时向你展示它的思考。它在每次对话后自我演化。你只需出现并交谈。

## 界面

页面构建为两个全高区域，在自然滚动中依次呈现：

**第一屏：Hero。** 你的名字以电影级文字揭示动画出现："Previously on {你的名字}。"Hero 填满你的整个屏幕。它沉浸、干净且郑重——一个视觉声明，表明你正在进入一段关系，而非打开一个工具。导航链接位于上方的固定头部中，使 Hero 完全聚焦于此刻。

**第二屏：时间线 + 内容。** 从 Hero 向下滚动，水平时间线立即出现在头部下方并定格——sticky，始终可见，随你继续向下滚动。其下方流动着对话区域：实时聊天（如果你在当下）或历史对话（如果你点击了过去的点）。

在最底部，聊天输入框坐落于半透明背景之上——`bg-background/90 backdrop-blur-md`——浮动在内容上方而不破坏视觉流动。它随你输入自动调整大小，从单行到最多三行。回车发送。Shift+Enter 添加换行。当 agent 正在回复时，发送箭头变为停止按钮。

### 水平时间线

这是你的主导航。一条细线水平横跨屏幕。线上的每一个点都是一次对话：

```
[← 加载更早] ●──●──●──●──●──●──●──●──●──●──●──●──●──●──●──○ [NOW]
             7/20  7/21  7/22  7/23  7/24  7/25  7/26  7/27
             14:30 09:15 11:00 15:45 10:30 16:00 08:00 13:30
```

日期在上，点在中，时间在下。选中的点会发光——放大，带有微妙的光晕。其他点更安静，半透明。最右边的点始终是空心的：**NOW**。它代表当下时刻，从你过去的任何一点都可以一键点击回到它。

用鼠标滚轮水平穿越时间线。在触控设备上，滑动。点击最左侧的"加载更早"可以回溯更久。

点击任意点。下方内容不会闪烁或清空——旧视图保持可见。新内容加载时，顶部会出现一道几乎不被注意的脉冲条。当准备就绪时，它替换旧视图。这就是**稳定的 slice 切换**——无闪烁、无跳跃、无在你记忆加载时的迷失瞬间。

## 观看 agent 思考

当你发送消息时，你不会看到带有"思考中……"的旋转图标。你会看到一个 **Phase Indicator**——一个分阶段、计时、透明的视图，精确展示 agent 在做什么：

```
🌀 切片时间中… 3s              →  ✓ 时间已切片
🔍 扫描记忆中… 2s              →  ✓ 找到 3 个对话
🧠 更新理解中…                  →  +1 观察到 · +1 强化
```

每个阶段都有标签、已用计时器和完成状态。你可以看到每个阶段花了多长时间以及它发现了什么。

当 agent 正在推理时——在"思考"阶段——你不会看到一堵文字墙。你会看到它正在处理的**当前行**，像字幕轨一样显示。新一行淡入，旧一行淡出。光标在最后一个字符处闪烁。它很微妙，但让 agent 的思考感觉真实——不是一个黑箱，而是一个正在工作的心智。

### 加载提示

当 agent 思考时，字幕上方的空间显示一条轮换提示——16 条教育性消息之一，在你等待时教你产品如何工作：

- "每次对话是 GitHub 仓库中的一个 Markdown 文件"
- "agent 在每次对话后自我演化——查看 Previously Bar"
- "点击时间线上的任意点回到那个时刻"

提示每 4 秒轮换一次，带有平滑的交叉淡入淡出。每次从一个随机点开始，这样你不会每次会话都先看到同一条提示。这是一个小细节，但它将等待变成了学习。

## Previously Bar：观看 agent 演化

在屏幕底部，输入栏的正上方，坐落着 **Previously Bar**——一条永久状态行，显示你的 agent 自我模型的状态：

| 状态 | 你看到什么 |
|-------|-------------|
| 🌀 演化中 | "自我演化中… 正在读取记忆…"——带有旋转动画的大脑图标 |
| ✅ 已变更 | "已演化：+2 观察到 · ↑1 强化 · ↓1 降级" |
| ✓ 无变化 | 一个静音的"已检查"——演化运行了但未发现新内容 |
| ❌ 失败 | 红色错误消息——演化失败，聊天不受影响 |

当演化有变更时，状态栏可交互。点击它打开一个对话框，显示完整的 `previously.md`——你的 agent 对你的完整理解，包含每一条信念、其证据链及其置信度。你可以精确看到 agent 认为它了解你什么，以及为什么。

每次对话后，演化栏更新。agent 在你面前学习，可见地，一次一个对话。

## 记忆如何形成

记忆不是你管理的东西——它在你交谈时自动形成。

一个 **slice** 在你于会话中发送第一条消息时开启。只要你持续交谈，它就保持活跃。静默 30 分钟后，它自动关闭。这是唯一的规则。没有容量限制，没有主题切换检测。纯粹的时间驱动切片。

当 slice 关闭时，系统在以下位置写入目录：

```
memory/episodic/slices/2026/07/27/1430/
  timeline/
    core.md       ← 对话内容（说了什么）
    agent.md      ← 认知内容（agent 在想什么）
  previously.md   ← 此时 agent 的自我模型快照
```

你永远不需要手动标注任何内容。系统在对话进行中自动维护元数据——focus、summary、tags、decisions、open loops。在关闭时，全局时间线索引更新，strand 索引织入新标签，演化工作流触发以更新 agent 的自我模型。

跨月跨年自上而下阅读，slice 目录树就是你的自传。Git 可比较、人类可读、可移植。

## 时间旅行

点击时间线上的任意点。历史视图加载——完整对话，完全按发生时的样子渲染：

- **你的消息**以一种气泡样式显示
- **agent 的消息**以另一种样式显示
- **每条 agent 消息旁边**，一个小链接写着 **Thoughts.**——点击它

Thoughts 链接打开一个 **Cognition Popover**——一个显示 agent 在那个精确轮次的内部独白的对话框。它所做的工具调用、所经历的推理、所考虑和拒绝的内容。你在回溯地阅读 agent 的心智，针对你历史中的任何时刻。

在历史对话上方，切片的 Previously On 块显示 agent 在那个时刻的自我模型——它当时对你相信什么。在下方，你会看到任何被继续推进的 open loops 或 decisions。

要返回当下，点击时间线右端的 NOW 点。

## 询问你的过去

当你的问题涉及之前的事情时，agent 不会自动搜索。它**决定**是否搜索。如果问题简单或自包含，它直接回复。如果需要更多上下文，你会看到它调用 `recall` 工具：

1. **Phase Indicator 显示"正在扫描记忆…"**——Flash 子 agent 正在读取全局时间线和 strand 索引
2. **一张卡片出现**——"找到 3 个关于装修项目的对话"及相关性原因
3. **agent 读取具体 slice**——你会看到"正在读取 7 月 25 日的对话…"带有真实日期
4. **agent 回复**——现在由那些过往对话的实际内容所充实

工具标签是人性化的，因为它们用真实数据渲染。你不会看到 `readSlice("2026-07-25-0915")`——你看到的是"正在读取 7 月 25 日上午 9:15 的对话。"agent 用你能理解的语言搜索你的记忆。

## Demo 模式：无需配置即可体验

Previously 自动检测你的环境。如果你配置了 GitHub token，你在使用自己的时间线。如果没有，你进入 **demo 模式**——无需设置。

[previously.ldwid.com](https://previously.ldwid.com) 上的在线站点**就是** demo。无需 GitHub token 访问，你自动探索来自 [WorldMemArena](https://github.com/WorldMemArena/worldmemarena) 基准测试的 20 个人物，每个人物都有数十个横跨多年的预填充对话 slice。没有独立的 demo 子域名、没有环境变量、没有配置。

一个小的 **"Demo"** 徽章出现在头部。点击它查看说明。你在 demo 模式下发送的消息不会被持久化——刷新页面，记录重置。但除此之外一切都功能完整：水平时间线、Phase Indicator、recall、Previously Bar、时间旅行、Thoughts 对话框。

点击 Hero 中的人物名称，打开一个 20 个人物卡片的网格。每张卡片显示一个名字和一段简短的人生故事。点击任意卡片切换——页面重新加载该人物的时间线。每个人物都运行完整系统：时间线导航、recall、演化。

### 开启你自己的时间线

从 demo 模式切换到自己的时间线：

1. 使用你自己的 GitHub 仓库和 GitHub 个人访问令牌（contents 读/写权限）部署 Previously。
2. 一旦设置了 `GITHUB_TOKEN`，demo 模式自动关闭——无需切换环境变量。
3. 你输入的第一条消息开启你的第一个 slice。

没有账号创建，没有数据库设置，没有种子数据。时间线从空白开始。记忆从你的第一次对话开始累积。

## 日常意味着什么

没有仪式。你不打开"新对话"。你不标记或分类任何东西。你不管理记忆。

- **出现**——打开页面。Hero 显示"Previously on {你的名字}。"向下滚动。时间线在那里，预加载了你最近的过去。
- **交谈**——输入并按回车。如果距离上次超过 30 分钟，一个新 slice 开启。agent 检查它对你的理解（previously.md）并回复。如果需要更多上下文，它会搜索。
- **看着它思考**——Phase Indicator 显示每一步，计时、标记。字幕滚动显示 agent 当前的推理行。Previously Bar 在对话结束后更新。
- **翻阅你的过去**——聊天上方的时间线是你的完整历史。水平、可滚动、可点击。每个点是一次对话。每条 agent 消息都有一个"Thoughts"链接。
- **询问过去**——"我关于 X 做了什么决定？"或"Y 是什么时候发生的？"agent 决定是否搜索。如果需要，你会看到搜索发生——Flash 返回指针，agent 读取 slice，答案由实际内容充实后返回。

这就是循环。无需设置、无需清理、无需线程管理。只有一段与一个持续学习的 agent 的持续关系。
