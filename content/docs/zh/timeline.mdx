# 时间线

<Callout variant="info">
你的记忆不是一个装满聊天线程的文件夹。它是一条连续的线。每个点都是一次对话。点击任意一点，你就到了那里——不是在搜索，不是在侧边栏中滚动，而是旅行到时间中的某个特定时刻。
</Callout>

时间线是 Previously 的核心导航模型——一条水平可滚动的线，每次对话都变成上面一个可见的点。它完全取代了聊天线程列表。没有装满命名对话的侧边栏，没有搜索栏。只有一条线，从你最早的记忆一直到此时此刻。

## 不是聊天列表，也不是搜索栏

大多数 AI 产品给你两样东西之一：一个垂直的命名对话线程列表，或一个搜索栏。两者都假设你会管理自己的记忆——命名东西、删除东西、记住三周前你把某个东西叫什么。

Previously 摒弃了这一假设。你的记忆按时间组织，因为时间是你永远不需要手动维护的轴。你不会给时刻命名。你按顺序经历它们。时间线反映了这一点。

## 它长什么样

时间线位于页面顶部，导航栏正下方。它在你滚动下方内容时保持可见——粘性定位，始终触手可及。

```
[← 加载更早] ●──●──●──●──●──●──●──●──●──●──●──●──●──●──●──○ [NOW]
                7/20  7/21  7/22  7/23  7/24  7/25  7/26  7/27
                14:30 09:15 11:00 15:45 10:30 16:00 08:00 13:30
```

时间线上的每个节点由三个垂直堆叠的元素组成：

- **日期**（上方）——对话发生的日期，简短格式
- **圆点**（中间）——过去的对话用实心圆，NOW 用空心圆
- **时间**（下方）——对话开始的小时和分钟

一条细水平线贯穿所有圆点，将它们连接起来。它在说：这些时刻不是孤立的。它们属于一个连续的故事。

选中的节点会发光——圆点略微放大并带有光晕环。未选中的节点更安静，呈半透明灰色。视觉层次清晰：一个时刻处于焦点，其余可访问但不抢占注意力。

更新的对话在右侧，更旧的在左侧。你从左到右阅读，从过去到现在——对世界上大多数人来说，这是自然的阅读方向。

## NOW

最右边的节点与众不同。它是空心的——一个空洞的圆，取代了本该填满的圆。它的标签不是日期，而是**NOW**。

这是过去与现在之间的边界。点击 NOW 会带你到实时对话——活跃的切片、输入栏、当下时刻。它永远在那里，永远可用，从你历史的任何一点只需一次点击就能到达。

NOW 节点也是一个视觉承诺：这条时间线尚未完成。总有空间留给接下来发生的事情。

## 点击任意圆点——时间旅行

这是时间线从装饰变为交互的地方。

点击时间线上的任意圆点。当前视图不会闪烁、不会空白、不会显示加载转圈。旧内容原封不动地停留在原地。内容区域的最顶部出现一条微妙的脉冲条——一条细线，几乎察觉不到——告诉你正在加载某些东西。当新内容准备好时，它会替换旧内容。没有闪烁，没有突兀的跳跃。

这就是**稳定切片切换**。浏览器中的 `SliceCache` 为最近查看的对话保持 5 分钟的热缓存，所以点击回到你刚访问过的圆点是瞬间完成的。

加载出来的是完整对话——每一次交流、每一条回复，完全如发生时的样子。在每条 Agent 消息旁边，有一个写着**Thoughts**的小链接。点击它，一个对话框会打开，显示 Agent 在那个确切回合中的思考。不是它*说了*什么，而是它说话时在*想*什么——它做出的工具调用、它经历的推理、它考虑并拒绝的决策。

这是可能的，因为每个切片存储了两份并行记录：`core.md`（对话）和 `agent.md`（认知）。"Thoughts"链接读取那个特定回合的认知记录。你正在查看的是 Agent 在过去的那个时刻的内部独白。

## 滚动浏览你的过去

时间线是水平的。你的鼠标滚轮——通常用于垂直滚动——改为水平滚动时间线。这是一个有意的选择：时间线不是你上下扫描的列表，而是一条你沿着它旅行的线，从左到右。

在触摸设备上，你水平滑动。在桌面端，你用滚轮滚动或用触控板拖拽。

"加载更早"按钮位于最左侧。点击它来获取更旧的切片——时间上更远的过去。时间线会延伸，新的圆点出现，线条变得更长。

## 每个圆点背后是什么

时间线上的每个圆点都对应一个**切片目录**——不仅仅是一个单独的文件，而是包含那个时刻一切内容的一个小文件夹：

```
memory/episodic/slices/2026/07/27/1430/
  timeline/
    core.md       ← 对话（说了什么）
    agent.md      ← 认知（Agent 在想什么）
  previously.md   ← Agent 在那一刻的自我模型
```

双时间线（`core.md` + `agent.md`）是 v0.5 的一项创新。在更早的版本中，Agent 的思考是临时的——它在对话期间存在，然后消失。现在它与对话一起被保存，使"Thoughts"链接成为可能，并赋予 Agent 反思自己过去推理的能力。

`previously.md` 快照捕获了 Agent 在那个确切时刻对你的理解。你可以看到它对你的印象如何随时间演变——它在第三次对话后相信什么，在第三十次对话后又是如何变化的。

## 全局时间线索引

视觉时间线的背后是一个单一的扁平文件：`memory/episodic/timeline.md`。它包含你历史中每个已关闭切片的摘要——每个对话一个条目。这是 recall 系统的起点。当 Agent 需要搜索你的过去时，它读取这一个文件，立即知道所有可用的内容，无需扫描目录或打开多个索引。

索引在新切片关闭时重新生成。如果 Agent 读取时索引超过 6 小时未更新，它会自动重新生成。你永远不需要操心它。

## 数据流

时间线由你的 GitHub 仓库（或开发环境中的本地文件系统）填充：

1. **初始加载**——页面获取全局时间线索引并将其渲染为一条水平的圆点带
2. **分页**——点击"加载更早"获取更旧的条目，向左延伸线条
3. **切片选择**——点击一个圆点加载该切片的完整内容（core.md 用于对话，agent.md 用于认知）
4. **NOW**——返回到实时、活跃的对话

## 交互模型

时间线不是一个装饰元素或你偶尔瞥一眼的侧边栏。它是产品的主要导航界面：

- **浏览**——水平滚动，一览你的过去
- **跳转**——点击任意圆点传送到那个时刻
- **反思**——点击任何历史 Agent 消息上的"Thoughts"查看它当时在想什么
- **返回**——点击 NOW 回到当下

没有文件夹。没有命名。没有搜索查询。只有一条穿越时间的线，而你决定在哪里停下来。
