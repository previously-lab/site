# 进化回路

Previously 会学习如何更好地对待你——但它不能悄悄改写自己。每一次改变都从证据出发，落进一份只追加的档案，事后可以被你逐条审计。进化回路跑在**切片边界**，分两个阶段，而且大多数时候，它根本不跑。

## 没有触发，就没有进化

进化不是例行公事。触发条件是确定性代码（`src/lib/evolution/triggers.ts`），不看心情：

- 某个 fitness 桶在最近 10 个切片里的净分 **≤ −3**；
- 或者本切片出现单条**挂着证据的 −2**；
- 外加 turn analyzer 的 `evolve_card.worth` 闸门、旧版卡片的强制升级，以及你明确的请求或纠正——「记住……」「以后别这样了」会立刻触发一次**仅卡片**的进化，不等切片边界。

没有触发，进化子 Agent 就完全不运行。它不会"顺便看看有什么可改的"。

## 第一阶段：方向

Direction Agent 评估 `memory/evolution/direction.md`——这条回路**学出来的奖惩模型**。它只有提议权，手里没有任何写入工具。

direction.md 固定四个小节：Direction / Anti-goals / Evidence / Log。它的内容纪律是**条件映射**——「当情境是 X 时，倾向于 Y」——永远不写状态；状态属于用户卡片的 Now 小节。「没有变化」是最常见的结果，此时什么都不写。史上第一份方向由 bootstrap 闸门兜底，标准相应放低。

## 第二阶段：唯一的写手

Previously Agent 是用户卡片和各家 playbook 的**唯一写手**。它通过逐条校验过的 mutation 工具编辑——永远是按条目修改，从不整文件重写；超出长度上限的写入会被拒绝，并附带压缩指令；同一个拒绝反复出现时，回路刹车会强制落地，不允许死循环。

## 计分，不许空口

fitness store 分五个桶：`card` / `recall` / `search` / `thinkdeep` / `interaction`，单条增量从 −2 到 +1。结构性的一条规定：**任何不挂证据的增量被强制归零**。分数可以错，但不能没有出处——这和回忆的证据锚定是同一条纪律。

## 验收档案，只追加

每次被接受的改动都追加进 `memory/evolution/mutations.md`，附上预期收益与证据。档案是只追加的，而且自带验收：**归档一条新改动时，会回头评估同一目标上的上一条改动**。持续丢分的改动会挣到一行 `**Evaluation: ineffective**`——这行字永远不会被删。没有回滚，没有冷却期，只有一份越来越长的、诚实的记录。

两个工程细节值得一提：playbook 注入的是同事的 **user 提示词**，永远不进静态系统提示词——前缀缓存的稳定性不允许；整个过程实时流式呈现在聊天里，一次被跳过的运行也会连同原因一起报告。

<Callout variant="info">
**一句话**：它在学习如何对你更好，但它走的每一步都留着脚印。
</Callout>
