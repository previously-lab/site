# 简介

<Callout variant="info">
Previously 用一条时间线取代了聊天线程，赋予你的 Agent 一个随着每次对话不断进化的活体自我模型，并将所有内容以纯 Markdown 格式存储在你自己的 GitHub 仓库中。
</Callout>

Previously 是一个个人 AI Agent，其核心理念只有一个：**记忆应该按时间组织，而不是按聊天线程。** 你出现，你交谈，你离开。当你回来时——几小时、几天或几周之后——你的 Agent 已经认识你。它一直在不断深化对你的理解。它会从你上次离开的地方继续。

## Previously 是什么

Previously 不是另一个让你在一次性线程中聊天的助手。它是一个持久化的 Agent，拥有三样任何聊天线程产品都不具备的东西：

1. **一条时间线，而非线程列表。** 每次对话都成为水平时间线上的一个点——点击任意一点，你就回到了那个时刻。没有文件夹，没有命名，没有"新建聊天"按钮。

2. **一个会进化的自我模型。** 你的 Agent 维护着一个名为 `previously.md` 的文件——它对你的持久化理解。它会观察、强化、纠正，偶尔也会遗忘。每次对话后，一个独立的模型会审查它学到了什么，并更新这份理解。随着时间推移，它会越来越擅长帮助你。

3. **透明的思考过程。** 当你的 Agent 工作时，你能看到它——不是一个带着"思考中……"字样的转圈图标，而是一个分阶段、带计时、实时展示它正在做什么的视图：扫描你的时间线、搜索相关记忆、更新它对你的理解。每一步都有标签、计时，并且可以展开。

一切都在你自己的 GitHub 仓库上运行。记忆是带有 YAML frontmatter 的纯 Markdown 文件。没有数据库，没有向量存储，没有专有格式。你的数据，你的仓库，你的掌控。

## "Previously on..." 的隐喻

名字源于电视：每集新剧集开始前，一段简短回顾提醒你上次发生了什么——刚好足够你接上剧情。Previously 为你的生活做着同样的事。每次你回来，它都会回顾你自己的时间线，把重要的内容带到前面，让你永远不会从零开始。

但这个隐喻远不止于此。在 v0.5 中，你的 Agent 不仅仅是在回顾——它会**形成对你的印象。** 把它想象成一个认识你多年的朋友。他们记得你的身份（你是谁）、你的模式（你做事情的方式）以及如何最好地帮助你（策略）。这种理解不会在对话之间重置。它会随时间累积、深化并自我纠正。

## 与聊天线程 Agent 的区别

主流 Agent 将你的生活分割成一个个聊天线程。每个线程从零开始。线程之间的记忆彼此孤立、脆弱且有损——需要外挂向量数据库、RAG 流水线和 prompt 黑客手段来近似实现本应是原生能力的特性。

Previously 用**时间切片**取代了线程：对话片段以纯 Markdown 文件的形式存储在时间线上。因为交互历史与记忆共享同一结构——按时间顺序排列的切片序列——跨会话回忆是系统固有的属性，而非事后修补。

但 v0.5 走得更远。在之前的版本中，系统在每次回复前都会强制向 Agent 注入上下文，无论它是否真的需要。现在，Agent **自己决定**何时需要查找某些内容。它只在对话确实需要时，才调用 `recall` 工具——一个遍历你全部记忆的快速搜索。不需要记忆的对话不会付出相应代价。这种从"推送"到"拉取"的转变，正是将被动 LLM 转变为真正 Agent 的关键。

## 词汇巡礼

五个术语承载了整个架构。

**Timeline** —— 你的记忆，可视化呈现。一条可水平滚动的线，上面每个点都是一次对话。上方是日期，下方是时间。一条细线贯穿所有点，从过去一直延伸到 NOW——一个位于最右端的空心圆点。点击任意一点，你就回到了那个时刻。旧视图在加载新内容时不会闪烁消失。内容在过渡期间保持可见。

**Slice** —— 一次对话片段。位于 `memory/episodic/slices/YYYY/MM/DD/HHMM/` 的目录，包含两份并行的记录：`timeline/core.md`（说了什么）和 `timeline/agent.md`（Agent 在想什么）。你开始交谈时打开，30 分钟静默后自动关闭。携带结构化的 YAML frontmatter：焦点、摘要、决策、未决事项、标签、情绪基调。

**Strand** —— 跨多个切片反复出现的话题关键词（如 `rust`、`work`、`health`）。全局时间线索引将每个 strand 映射到所有携带它的切片。Slice 回答"发生了什么、何时发生"，Strand 回答"它关于什么"。Strands 构成了时间线上轻薄、无损的语义层。

**previously.md** —— 你的 Agent 的活体自我模型。一个结构化的 Markdown 文件，分为长期记忆（身份、模式、策略——稳定，仅在你纠正时改变）和短期记忆（当前上下文——7 天后自然过期）。每次对话后，一个专门的进化工作流会审查新的观察、强化已有信念、纠正矛盾并过期过时的上下文。这个文件取代了早期版本中旧的 profile.md 和记忆节点系统。

**Recall** —— Agent 的搜索引擎。当对话涉及过去时，Agent 会调用 `recall` 工具，该工具启动一个快速的 Flash 子 Agent 扫描全局时间线并返回相关切片的指针。主模型随后完整读取这些切片。Flash 快速而近似；主模型审慎而彻底。两者互不替代。

| 术语 | 层级 | 角色 | 速度 |
|------|------|------|------|
| Timeline | 导航 | 记忆的水平可视化浏览器 | 即时（客户端） |
| Slice | 情景层（何时） | 记录发生了什么 + Agent 想了什么 | 存储，非检索 |
| Strand | 语义层（什么） | 跨切片的关键词 | 切片关闭时构建 |
| previously.md | 自我模型 | Agent 对你的持久化理解 | 每次对话后更新 |
| Recall | 检索 | 遍历整个时间线的按需搜索 | 约 500ms Flash 扫描 + 深度读取 |

## 研究基础

情景/语义的二分并非随意之举。它基于 Endel Tulving 的情景记忆与语义记忆理论（1972）以及情境依赖记忆研究（Godden & Baddeley 1975；Smith & Vela 2001）。Slice 编码了*何时*（情景层）。Strand 编码了*什么*（语义层）。previously.md 自我模型编码了*谁*——Agent 对其所帮助之人的不断进化的心智模型。

## 状态

Previously 目前是 **EXPERIMENTAL（实验阶段）**——早期开发，尚未准备好用于个人或生产环境。这是一个单人研究项目，计划长期维护。

v0.5 中目前可用的功能：带稳定切片切换的水平时间线（点击任意点，无闪烁）、带 Phase Indicator 的流式聊天（分阶段、带计时、字幕式推理展示）、previously.md 自我模型含 7 种变更操作（observe、reinforce、contradict、discard、expire、promote、demote）、作为独立工作流与聊天并行运行的进化系统、通过 Flash 子 Agent 实现的按需 recall、双时间线架构（每个切片包含 core.md + agent.md）、机械式认知提取（自动进行，无需模型参与）、16 条提示语的加载轮播、多人物 demo 模式（20 个 WorldMemArena 人物）、推理深度控制（低/中/高）、带路径白名单的 GitHub 原生存储，以及中英双语国际化。

Strand 索引现在已被 recall 主动使用——这是 v0.5 相较 v0.4（其时 strand 仅写入不读取）的改进。更丰富的带滚动摘要的一等公民 strand 仍是未来的里程碑。
