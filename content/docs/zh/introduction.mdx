# 简介

Previously 是一个按时间拥有记忆的 AI agent。它和其它 AI 助手之间只有一个根本区别，但这个区别改变了一切：**它按"什么时候"记忆，而不是按聊天线程。**

## 没有聊天线程，只有一条时间线

主流助手把你的生活切成一个个一次性对话，每个都从零开始。Previously 里没有对话列表：你说过的每一段话都会变成时间线上的一个**切片**，记下发生了什么、发生在什么时候。几小时后、几天后、几周后回来，你接着同一条时间线往下聊——像一部长跑的剧集，而你永远不需要"开一个新对话"。

## 回忆是一位同事，回答带着证据

当你问起过去，回答你的不是向量数据库，而是一位**回忆同事**：它亲自翻阅你的时间线，用自然语言作答，每个结论都锚定原文引用。「这个我们不记得聊过」也是一个诚实的答案。

与此同时，一张**用户卡片**在每次对话结束后悄悄更新——你是谁、最近在做什么、接下来打算做什么。它认得你，不是因为你每段对话开头都重新自我介绍，而是因为它一直在场。

## 跑在你拥有的基础设施上，记忆是你的

Previously 是同一颗内核的两种跑法：部署到你自己的 Vercel 项目（推荐），或者在本机用 npm 运行。无论哪种——没有我们的服务器，没有平台数据库。你的记忆是一个普通 git 仓库里的纯 Markdown 文件，从第一天起就属于你：可以备份，可以搬走，可以用任何工具打开。

<Callout variant="info">
**一句话**：Previously 相信记忆的单位是时间，不是对话。修好了记忆模型，"管理对话"这件事本身就不存在了。
</Callout>
