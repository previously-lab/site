Strand 是一个贯穿每个携带它的时间切片的关键词——构建在情景时间线之上的语义层。切片按时间说*发生了什么*，而 strand 按主题说*它是关于什么的*。

## 问题：情景记忆没有话题索引

时间切片按时间顺序组织你的历史。你可以问"昨天下午发生了什么"，然后找到对的切片。但你无法轻易回答"我所有讨论过关于 Rust 的一切"——这个问题是*跨时间*的，而不是沿着时间的。

你需要两个坐标轴：

| 记忆类型 | 组织方式 | 单元 | 回答的问题 |
|---|---|---|---|
| **情景记忆** | 时间 | Slice | "什么时候发生了什么？" |
| **语义记忆** | 话题 | Strand | "关于 X 说过什么？" |

Strands 填补了语义轴。它们是按时间记录的切片在按话题维度的对应物。

## 工作原理

一个切片在其 YAML frontmatter 中携带 `tags`——像 `rust`、`async`、`deployment` 这样的关键词。每次一个切片关闭时，这些标签被编织进一个全局文件：

> `memory/episodic/strands.json`

该文件中的每个键是一个 **strand**（一个标签）。每个值是被该关键词标记的所有切片相对路径列表——那个事物跨越时间的完整历史。

```json
{
  "rust": [
    "2026/06/22/1400",
    "2026/07/01/0915",
    "2026/07/08/1630"
  ],
  "async": [
    "2026/06/22/1400"
  ],
  "deployment": [
    "2026/07/08/1630"
  ]
}
```

路径是相对的：没有 `slices/` 前缀，没有 `.md` 扩展名。`sliceIdToRelPath` 将像 `2026-06-30-1430` 这样的切片 ID 转换为 `2026/06/30/1430`，这样系统就能直接定位到正确的目录。

## 派生而来，而非手动编写

Strands 没有单独的编写步骤。它们**完全派生自**每个切片 YAML frontmatter 中的 `tags` 数组。标签由系统在每轮元数据更新中维护——它读取对话、分类话题并写入标签。这些标签自动成为 strand。

这个循环是：

1. **系统维护元数据**——将 `tags` 写入活跃切片的 frontmatter
2. **切片被持久化**（在 30 分钟静默后关闭，或在对话中做快照）
3. **`updateStrands(slice)` 运行**——读取 `strands.json`，将每个标签作为键合并，追加切片的相对路径（去重后），写回

标签编织成 strand。你永远不会直接编写 strand。

## Strands 何时写入

`updateStrands` 在两个地方运行：

- **切片关闭时**：切片目录完成定稿后，`updateStrands` 将切片的标签发布到全局索引中。
- **活跃切片快照时**：当对话进行中保存快照时，`updateStrands` 也会运行——但仅当该切片至少有一个标签时。这意味着进行中的切片在关闭前就会出现在 strand 索引中。

结果是：即使是活跃切片，`strands.json` 也始终保持最新，因此 recall 扫描永远不会因为切片尚未关闭而错过某个标签。

## Recall 中的 Strands（v0.5）

在 v0.4 中，strand 索引是**只写**的——它被构建和维护，但没有 recall 代码以编程方式读取它。系统信任 Agent 在需要时手动打开 `strands.json`。

在 v0.5 中，recall 系统**主动使用 strand 索引**。当 Agent 调用 `recall` 工具时，Flash 子 Agent 在其多步探索中查阅 `strands.json`：

1. **读取全局时间线**——一个扁平文件，所有可用切片一览
2. **读取相关 strands**——跨时间追踪话题关键词，找到按主题连接的切片
3. **读取特定切片**——打开看起来最有希望的切片

这意味着基于话题的搜索现在是 recall 的一等公民功能，而非手动回退方案。如果你在三年间的 30 个切片中谈论过"rust"，recall 系统会通过 strand 索引找到它们全部，然后完整读取最相关的那些。

## 类型定义

`StrandIndex` 类型是一个普通的字符串键映射：

```typescript
interface StrandIndex {
  [strand: string]: string[];
}
```

如果 `strands.json` 还不存在——即没有任何切片有过标签——`readStrands()` 返回一个空对象 `{}`。写入总是生成美化打印的 JSON。

## Strands 还不是什么（尚未实现）

今天的 strands 是一个轻薄、无损的关键词到切片路径的索引——准确、最新，并被 recall 主动查询。它们还不是：拥有自己滚动摘要、自己元数据和专用叙事线索的一等公民实体。

一个更丰富的 strand——维护自己的摘要，随新切片加入而更新，承载跨越时间的叙事弧线——是一个明确的未来里程碑。当前的 strand 是这个索引：从关键词到切片路径的映射。这个映射现在驱动着 recall。摘要会有的，在后面。
