# Getting Started

Previously runs on your own machine: one npm package is the whole product. There is only one command you need to remember.

**Requirements**: Node.js ≥ 20. No Docker, no git installation needed.

## Install

```bash
npm i -g previously-client
previously
```

## The first run: one wizard

The bare `previously` command is the front door. On first run it walks you through an init wizard in the terminal and settles everything:

1. **Sets up the runtime** — creates `~/.previously` for kernel versions, logs, and process state.
2. **Sets up your memory** — creates your memory repository at `~/Documents/Previously`; if a Previously repo already lives there (say, cloned back from a backup), it adopts it — history fully preserved.
3. **Picks an engine** — the wizard detects agent CLIs already on your PATH (Claude Code, Codex, Kimi Code) and offers to configure a detected subscription as the bridge engine: zero API keys, zero extra cost. If nothing is detected, or you'd rather bring your own, it asks for an API key (BYOK). The trade-offs are in [Two Engines](/docs/two-engines).
4. **Transcribes your existing history** — turns your other local agents' existing conversation logs into slices on the timeline. This step costs zero tokens: transcription is deterministic parsing, not a model call.

Any step that would spend tokens shows you the estimate first and defaults to not running. Nothing quietly spends your money.

## Start, open, talk

```bash
previously start   # start the kernel in the background
previously open    # open the Web UI in your browser
```

The Web UI lives at `127.0.0.1:3210` — reachable only from your own machine. Open it and type your first message. That message opens the **first slice** on your timeline: from this moment on, memory accumulates.

No account creation, no database setup, no seed data.

## The dashboard: `previously status`

Once you're running, the bare `previously` (or `previously status`) is your dashboard: whether the kernel is up, the Web UI address, memory repo state, engine detection, transcription progress. The everyday rhythm of starting, stopping, and reading logs is in [Everyday Commands](/docs/everyday).
